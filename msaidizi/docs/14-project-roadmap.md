# 14 — Project Roadmap

## Purpose of this document
This document will track the phased development plan for Msaidizi and current progress.

## Phases
- **Phase 0 — Product Discovery / Foundation** (current): project scaffolding, documentation structure, technology setup. No feature code, no schema, no auth.
- **Phase 1 — Product & UX Research**: complete docs 01–08.
- **Phase 2 — Data & API Design**: complete docs 09–10.
- **Phase 3 — Core MVP Implementation**: auth, profiles, categories, services, search, verification, service requests, quotes, bookings, messaging, reviews, notifications, admin dashboard.
- **Phase 4 — Future Features**: payments, advanced maps, provider subscriptions, promotions, advanced analytics, mobile apps, AI-assisted matching.

## Status
Currently in **Phase 0 — Product Discovery / Foundation**.
